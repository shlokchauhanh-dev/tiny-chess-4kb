A deterministic Python chess engine packed into 4 KB. It plays the bounty env over UCI with alpha-beta, quiescence search, and a fixed node budget.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
